Pusat Ekspor Laporan Keuangan & Kasir

Cetak dan unduh laporan arus kas resmi DIALOG COFFEE dalam format Microsoft Word (.docx) dan Adobe PDF (.pdf) berstandar akuntansi lengkap dengan kop surat, metrik keuangan, rincian nota, dan tanda tangan pengesahan.

Cakupan Transaksi Ekspor:
FORMAT PDF
📄

Laporan Resmi PDF (.pdf)

Dokumen siap cetak dengan layout A4, logo DIALOG COFFEE, kartu ringkasan keuangan, tabel transaksi lengkap, dan kolom tanda tangan barista on duty & manager.

  • Header resmi & logo DIALOG COFFEE
  • Ringkasan Total Masuk, Keluar, Laba Bersih
  • Tabel rincian per nota & per item
  • Kolom pengesahan Barista & Manager
FORMAT WORD (.DOCX)
📝

Dokumen Microsoft Word (.docx)

Format dokumen Word asli OpenXML (.docx) yang kompatibel 100% dengan Microsoft Word, Google Docs, dan WPS Office. Bebas diedit kembali untuk pembukuan.

  • Native XML Word Document (.docx)
  • Tabel terstruktur rapi dengan styling monochrome
  • Layout landscape A4 untuk ruang baca luas
  • Kolom tanda tangan & pengesahan formal
SPREADSHEET
📊

Lembar Sebar Excel (.csv)

Data mentah tabular terformat CSV standar UTF-8 untuk analisis pivot lanjutan di Microsoft Excel atau Google Sheets.

  • Kompatibel dengan semua spreadsheet
  • Format kolom terpisah rapi
  • Ukuran berkas sangat ringan

🖨️ Printer & Struk Kasir

Pengaturan pencetakan struk transaksi kasir. Kompatibel dengan printer thermal POS 80mm/58mm (Bluetooth, USB, WiFi, Network) serta opsi simpan struk format PDF jika printer belum terhubung.

💡 Cara Kerja Pencetakan:
  • Dengan Printer Fisik: Klik tombol Cetak Printer pada struk untuk mencetak langsung ke printer kasir yang terpasang.
  • Tanpa Printer (Simpan PDF): Klik tombol Simpan PDF pada struk untuk mengunduh struk digital resmi ke memori perangkat.

🔥 Database Real-Time Cloud (Google Firebase)

Koneksi database real-time berjalan otomatis di latar belakang via WebSocket untuk mengamankan rekapan closing, transaksi kasir, sinkronisasi menu & PIN, serta sistem Anti Dual-Login ke Google Firebase Realtime Database (Singapura).
